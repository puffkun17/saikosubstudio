# 片源匹配与语种甄别经验备忘

**日期**：2026-07-28  
**状态**：已落地最小保守修复（危险 contains 不自动 + 近分确认；语种启发式英语优先；轨名「主字幕」+ 注解「默认：中文」/「原文」）

## 1. 案例：Elite Force → Lab Rats: Elite Force（2016）

### 现象

文件：`Elite.Force.S01E01....-Chs.srt`  
解析片名：`Elite Force`，无年份，剧集。  
自动结果常把 **Lab Rats: Elite Force** 列为最佳并写入片源。

### 根因

1. 标题匹配为 **contains**，且方向是 **查询 ⊂ 候选片名**（`eliteforce` ⊂ `labratseliteforce`），不是 exact。  
2. 剧集固定加 `type:tv`（+180），contains 只加约 +20 → 总分仍过自动门槛。  
3. **旧规则**：`veto:title-contains-only` 曾依赖「有无年份」等条件，无法挡住「有年但系列名包含查询」的热门剧。  
4. 同分/近分时靠 TMDB popularity → 迪士尼热度压过其他 Elite Force 相关条目。

### 已落地规则（contains 要分方向）

| 方向 | 例子 | 自动？ |
|------|------|--------|
| **查询 ⊂ 片名**（危险） | Elite Force → Lab Rats: Elite Force | **禁止** → 确认 |
| **片名 ⊂ 查询**（恢复） | Down Cemetery Road ⊂ … XXX S01E03 | **允许**（过门槛且非近分） |
| exact / loose-exact | 正名一致 | **允许**（仍受近分 / 多同名补年约束） |

- 本轮候选 **top1 与 top2 分差 &lt; 30** 且 top1 本可自动 → 降为确认（`close-score`），禁止只靠热度掷骰。  
- exact 多条分不清 → 继续走既有「补年份」路径。

### 回归

`scripts/regression-subtitle-core.mjs`：

- Elite Force 仅返回 Lab Rats contains → `tmdbData === null`，保留确认 notice。  
- Down Cemetery Road XXX 恢复路径仍可自动写入「坟场回路」。

## 2. 语种未能精确判定：原因与用户甄别

### 截图类现象

同包内：

| 文件 | 系统标签（例） |
|------|----------------|
| `...MeGusta.srt`（无语种后缀） | 误标 **法语** |
| `...MeGusta-Chs.srt` | 正确 **简中** |
| 另一集无后缀 | 误标 **西语** 等 |

### 技术原因（分层）

1. **文件名无 token**（无 `chs` / `eng` / `en`）→ 退回 **内容启发式**。  
2. 旧内容检测：法语/西语停用词 ≥2 即判定，**可压过英语**（英文里偶发 `que` / `pas` / `la` 等）。  
3. 文件名 token `fr` 本身较宽（本例主因仍是内容侧）。  
4. 主路径已 **English-only secondary**：误标为 fr/es 的轨会被 demote，**不会自动进原文槽**，但列表徽章仍会误导，用户需手动点选。

### 已做的最小纠偏（算法）

西欧语判定改为：信号需 **明显强于英语信号** 才返回 fr/es（重音字符仍可直接判）。减少「从 0 猜错」的概率。

## 3. 用户参与：要甄别什么、如何降低成本

### 需要用户参与的时刻

| 场景 | 用户该做的事 | 应避免的事 |
|------|----------------|------------|
| 片源危险 contains / 近分 | 在已列出的候选里点选正确项；或补首播年后再搜 | 从空白重新搜完全无关片名 |
| 语种徽章可疑 | 把正确文件绑到「主字幕 / 原文」槽；或一键纠正语种（未来） | 重新导入整包、重跑全流程 |
| 无英语轨、仅有 fr 等 | 明确提示「未自动绑定原文；可手动指定」 | 静默空槽且无说明 |

### 降低甄别成本的产品原则（纠偏，而非从 0 到 1）

1. **保留猜测，标注不确定**：徽章旁「不确定」或弱样式，点击展开「改为英语 / 简中 / 繁中」。  
2. **槽位预填建议**：主路径未绑原文时，列出「可能的原文候选」文件（按体积/与中文行数接近），一键填入原文槽。  
3. **片源确认复用列表**：确认 UI 直接展示当前排序候选 + 「不是这个？补年份」，不要清空。  
4. **文案对齐用途**：  
   - **主字幕** + 注解 **默认：中文** — 主名保持短，默认说明不挤占选择器列。  
   - **原文** — 替代「第二语言」，语义是对白原文（主路径为英语）。  
5. **未来**：主字幕可选手动指定 **简中 / 繁中**（在自动简中优先之上的用户覆盖），属于纠偏控件，不是新导入流程。

### 已改文案（本轮）

- 轨道槽：主名 `主字幕` / `原文`；「默认：中文」作主字幕次行注解（`text-faint`，可 truncate）  
- 样式与取样等用户可见「第二语言」→「原文」  
- 预检描述：中文轨 / 原文轨 / 其他语种轨

## 5. 原则备忘

> 宁可确认，不可错认。  
> 自动只信任 exact（及已证明的 Lucky 跨度消歧、以及「片名⊂查询」的后缀恢复）；**查询⊂片名** 的 contains 与近分只展示。  
> 语种与片源的失败应以「改标签 / 改绑定 / 选候选」收尾，而不是推倒重来。
