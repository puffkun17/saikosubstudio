## 已确认方向

### 批量双语字幕样式转换

**目标**：为已经确认内容与时间轴正确的双语字幕，提供本地批量 `SRT -> ASS` 转换，并统一套用一份样式模板。

**产品定位**：这是格式化与产出工具，不承担片源匹配、字幕翻译、自动校轴或跨文件配对职责。

#### 基本流程

1. 从上传页进入“批量套用样式”。
2. 本地读取多个字幕文件，形成转换清单。
3. 展示文件名、行数、时间跨度、双语结构状态、警告和预计输出名。
4. 选择一份现有样式模板，并用代表性样本预览结果。
5. 选择受控的输出选项。
6. 浏览器本地生成 ZIP 下载包与转换报告。

#### 输入与字幕结构

- 首版以 `.srt` 为主；压缩包输入可复用现有本地解包边界。
- 单个 cue 内已换行的双语内容直接转换。
- 中外语分占相邻 cue、且时间戳完全相同的内容，可在高置信度下折叠为双语 ASS 事件。
- 时间戳不一致、语言结构不明确、重复事件异常的文件标为“需确认”；默认不擅自合并。
- 原始 `.ass` 默认跳过，避免重写复杂既有样式；后续如有需要，单独设计“ASS 重套样式”模式。

#### 受控输出选项

**文件命名**

- 保留原文件名：`原名.styled.ass`
- 剧集标准名：`片名.S01E01.语言.ass`
- 片源标准名：`片名.年份.语言.ass`

仅当 TMDB 条目已明确确认时，片名、年份和集号才可参与命名；信息不足时自动退回原文件名。清单必须预览“原名 -> 输出名”并处理重名。

**片尾署名**

- 不添加。
- 仅添加本次整理署名。
- 保留原署名并追加本次整理署名。

署名固定添加在最后一条字幕结束后约 1.5 秒，持续约 5 秒，并使用独立、居中的 ASS `Credit` 样式。批量任务只使用一份统一署名，不提供逐文件编辑。

**TMDB 附赠内容**

- 不附赠。
- 附赠海报。
- 附赠海报与基础资料文本。

仅当所有输出明确对应同一已确认 TMDB 条目时开放。附赠内容位于 ZIP 内，不嵌入字幕文件：

```text
Batch_Output.zip
  Show.S01E01.zh-en.styled.ass
  Show.S01E02.zh-en.styled.ass
  poster.jpg
  metadata.txt
  conversion-report.txt
```

`metadata.txt` 固定记录标题、原始标题、年份、TMDB ID、样式模板名和生成时间。默认不收录剧情简介、剧照合集或其他非必要资料。

#### 本地与安全边界

- 所有字幕读取、转换和 ZIP 生成均在浏览器本地完成。
- 不上传字幕内容、文件路径或转换结果。
- 采用分批处理、进度显示和取消入口。
- 建议首版限制：30 个文件或 60 MB 输入；输出体积持续计量。
- 部分失败时保留成功文件，并在 `conversion-report.txt` 中逐项说明失败原因。

#### 明确不做

- 自由脚本化命名规则。
- 批量爬取、自动搜索或不经确认的 TMDB 匹配。
- 批量自动校轴、跨文件自动找配对、翻译或重写译文。
- 将海报或元数据嵌入 ASS 字幕正文。

#### 上线前验证

必须建立固定输入/输出样本，至少覆盖：

- 同 cue 换行双语。
- 同时间戳的相邻双语 cue。
- 时间戳接近但不相同的 cue。
- 特殊字符、转义、歌词、声音说明和片尾署名。
- 多编码输入与长文件名。
- 多文件重名、无 TMDB 信息、已确认单一 TMDB 信息。

验证内容包括 ASS 事件数、时间戳、语言行顺序、字体/颜色/描边字段、输出命名、ZIP 清单和失败报告。不能只依赖预览画面判断成品正确性。
