# 分支政策

> 产品与算法的真相来源、PR 目标，以及当前范围边界。

## 真相分支

| 分支 | 角色 |
| --- | --- |
| `cf-pages-hosted` | **公测 / 托管真相线**。功能、效果、合并算法、人工协助交互均以此为准。产品向 PR 默认合入此分支。 |
| `main` | **开源自部署裁剪线**。算法与行为必须来自 `cf-pages-hosted`，再剥离商业私有 API / 密钥依赖；禁止在 `main` 另起一套合并实现。 |

## PR 约定

1. 合并质量、人工复核、工作台协助等产品改动 → **base = `cf-pages-hosted`**。
2. 仅当改动明确属于开源打包、自部署文档、去私有 API 时，才以 `main` 为 base，且应能追溯到托管线同源行为。
3. 禁止再开「tip 互相依赖」的长链 PR（例如 EP-0 / REL 那种 base 指向上一个 tip）。需要历史改动时，从 `cf-pages-hosted` 重新开分支。
4. 2026-09-03 已关闭过期链路：PR #6–#13（EP-0 / REL tip 链，未对准托管线）。

## 产品边界（当前）

- **要做**：高质量智能化双轨合并；人工介入时的协助交互（差异复核、低置信度队列等）。
- **不做**：翻译 / NMT / LLM 译后重切，以及任何把翻译流水线并入主产品的方案。
