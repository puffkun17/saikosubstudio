# 字体来源与许可

## Source Han Sans / 思源黑体

- 项目：Adobe Source Han Sans
- 站点文件：`public/fonts/SourceHanSansCN-VF.woff2`
- 配置：简体中文可变 WOFF2，版本 `2.005R`
- 官方来源：`https://github.com/adobe-fonts/source-han-sans`
- 原始下载：`https://raw.githubusercontent.com/adobe-fonts/source-han-sans/release/Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2`
- 许可证：SIL Open Font License 1.1
- 许可证副本：`public/fonts/SOURCE_HAN_SANS_LICENSE.txt`

OFL 1.1 允许字体随软件使用、嵌入和再分发，包括商业软件；字体文件本身不得单独出售。本站使用 Adobe 发布的未修改版本，未使用第三方修改版，也未更改其保留字体名称。
