# 控件内边距 v1.3（文字到边缘的距离全部用 token）

Derek 的标注（旧版「样式参数」抽屉，2×）：面板顶 57px、分段控件 87/30/25、「辅助线」按钮 26、选择框文字靠右、距离 120px、标签 43、「剧照轮播」压住面板底边。v1.3 把这些距离都收进同一组 token（`app/ds.css`）。

| Token | 值 | 用在 |
|---|---|---|
| `--ds-ctl-h` | 36px | 按钮、选择框、输入框高度 |
| `--ds-ctl-h-sm` | 32px | 分段控件选项、紧凑按钮 |
| `--ds-ctl-h-xs` | 28px | 标签 chip、页码 |
| `--ds-ctl-px` | 12px | 按钮、选择框、输入框：文字到左右边 |
| `--ds-ctl-px-sm` | 10px | 分段选项、chip |
| `--ds-ctl-lh` | 20px | 控件内单行行高（高度由高度 token 决定，上下自然相等） |
| `--ds-ctl-gap` | 6px | 图标到文字 |
| `--ds-panel-pad` | = `--ds-pad-card`，16 / 12 | 面板、停靠面板标题栏、弹窗、菜单、提示条 |
| 样式参数滑块 | 控件内 8 / 控件之间 12 / 分组之间 16 | `.ds-slider`、`SettingSection` |

规则：
- 选择框文字一律左对齐，距左边 `--ds-ctl-px`（以前是 `text-right w-40`，文字跟标签之间空出一大块）。标签和选择框用 `56px | 1fr` 两列网格，「中文 / 原文 / 位置」三行对齐；「画面规格」标签较长，改成标签在上、选择框在下。
- 垂直居中靠 flex 加固定行高实现，不靠上下 padding。
- 停靠面板列表项：图标框和标题都是 20px 行盒，上下 padding 用 `--ds-gap-item`（8）。
- 「剧照轮播」开关已移进剧照面板（`.ds-dock__body > .ds-check`，上下 12、左右 16），不会再压住面板底边。

## 实测（pr4-rhythm 预览，无头 Chrome，`/tmp/pl/pad.mjs`）

测量方式：在每个可见控件上取文字节点的 Range 矩形，计算它离控件上下边的距离 T/B；选择框按字号 × 1.25 的行盒估算。结果见 PR 说明和 `pr4-shots/final/after/*-pad.json`。

| 控件 | 桌面 1280×800 | 手机 390×844 |
|---|---|---|
| 按钮（单行） | |T−B| ≤ 1.2px | |T−B| ≤ 1px（底栏「上图标、下文字」的按钮除外，这是有意的版式） |
| 分段控件 | ≤ 1.3px | ≤ 1.3px |
| 选择框 | 左对齐，左距 13px（12 + 1 边框） | 同左 |
| 停靠面板列表项 | |T−B| ≤ 1px（单行 36px，两行 54px） | 同左。之前 T8/B11：图标框带 2px 上外边距，把单行项撑高到 38px |
