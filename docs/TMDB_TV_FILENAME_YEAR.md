# 剧集文件名年份：丢弃与纠正备忘

日期：2026-07-26  
关联：`docs/TMDB_SEARCH_RETROSPECTIVE.md`（电影年份采纳）、`2927e391`（季跨度消歧）

## 现象

用户上传压缩包：

`幸运女神 Lucky 1080p 第1~2集 (2026).7z`

包内字幕为行业常见 scene/WEB 格式：

`Lucky.2026.S01E01.1080p.WEB.h264-ETHEL.[语种].[ext]`

人眼信息完整：英文名、年份、季集。系统却进入「未匹配 / 请补充年份」手动检索，且年份栏为空；同名剧列表只有 2003 / 2007 / 2022 等旧条目。

## 直接原因（两处叠加）

### 1. 识别层：认出剧集后主动丢掉年份

`parseMediaFilename` 一旦匹配到 `SxxExx`，旧逻辑为：

- 不调用电影用的 `findReleaseYearAnchor`
- 用正则把标题里的 `19xx|20xx` **抹掉且不写入** `parsed.year`

于是 `Lucky.2026.S01E01...` 只剩 `title=Lucky`，`year=undefined`。

### 2. 查询/采纳层：剧集年份只认手填

`searchTmdb` 在 `2927e391` 起写成：

```text
剧集：文件名通常无年；优先用手填年份区分同名。
year = isEpisodeQuery ? manualYear : (parsed.year || ...)
```

即便文件名里有年，自动链路也不会用于 `assessTvYearFit` 消歧。  
同名精确命中 ≥ 2 且无年 → `needsYearDisambiguation` → 提示「文件名缺少年份」。

### 3. 调用层加剧丢失（次要）

选任务后常用 `cleanFilename(file) + epKey` 发起搜索。`cleanFilename` 对剧集只返回片名、不带年，等于把已解析到的年在入口又丢掉一次。应优先传入**原始身份文件名**。

## 「文件名通常无年」从哪来

不是对 scene 命名的抽样结论，而是实现假定：

| 时间线 | 行为 |
|--------|------|
| 更早 | 剧集查询 `year` 恒为空（电影才用解析年） |
| `2927e391` | 引入季跨度消歧 + 手填年；注释写「剧集：文件名通常无年」 |
| 本次 | 纠正：剧集也保留并使用 `Title.Year.SxxExx` 中的年 |

该假定与发行常见格式冲突：`Show.2026.S01E01.1080p...` 把年放在片名与季集之间，恰恰是为了消歧。

## 当前纠正

1. **解析**：episode 截断后的前缀若以 `Year` 结尾，写入 `parsed.year`；数字片名后缀（1917 / 2049 等）仍不当年。
2. **检索**：剧集年优先级为  
   `parsed.year` → `fallbackParsed.year` → 任务文件解析年 → 手填年。
3. **入口**：有身份文件名时 `searchTmdb(identitySourceName)`，避免先 `cleanName` 再搜。
4. **预填**：手动检索表单预填解析到的年；「请补充年份」文案改为「未能从文件名得到可用年份」，不再默认指责文件名无年。
5. **回归**：`Lucky.2026.S01E01...` 多同名时须无手填即可自动命中 2026 条目；`Blade.Runner.2049.S01E01` 不得把 2049 当年份剥掉。

## 分层约定（与复盘备忘对齐）

| 层 | 剧集年份职责 |
|----|----------------|
| 识别 | 文件名能抽年就保留；弱身份才要求手补 |
| 查询 | 片名检索为主；年主要用于本地评分/否决，不必强塞 TMDB `year=`（发行/观影年与首播年可能不同） |
| 采纳 | 有年则走 `assessTvYearFit`；无年才季跨度降权或「请补充年份」 |

优先级建议：

1. 包内字幕文件名本体（`Title.Year.SxxExx`）  
2. 压缩包名等外层线索（中文名、括号年等，后续可加强）  
3. 用户手填（首播年优先；发行/观影年为 soft）

## 经验（可复用）

- **不要把「实现时没接到样例」写成「行业通常如此」。** 注释里的经验判断要能回溯到样例或明确「临时简化」。
- **电影与剧集的年语义不同，但不能因此在识别层物理删除字段。** 电影年偏上映年；剧集年偏首播/发行年，采纳规则可以不同，解析结果应保留。
- **清洗展示名 ≠ 丢弃检索信号。** `cleanFilename` 可以只展示片名；年应走 `parsed.year` 或原始文件名，而不是从查询串里蒸发。
- **负样本要覆盖「有年却仍要人补年」。** 仅测「无年时的幸运路径 / 手填年」会漏掉本次回归。

## 未决 / 后续

- 压缩包名中的中文名（如「幸运女神」）尚未作为主检索词；内层英文足够时应已命中，不足时再吃包名。
- `第1~2集` 区间写法与括号年 `(2026)` 的包名解析仍可加强。
- TMDB 尚未收录的新剧：即使文件名有年，也无法自动命中；应明确失败态，而不是伪装成「文件名缺少年份」。
