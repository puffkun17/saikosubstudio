# UI Spec v1.2 — SaikoSubStudio

- 来源：postlaunch-zhuanan.md（专案实施）与 postlaunch-pa.md（PA）两份独立审查取交集。
- 实现：`app/ds.css` 中的 `--ds-*` 设计变量和 `.ds-*` 基础类。新写或重排的界面只能用这些；旧的 `--v4-*` / `--v5-*` 颜色变量保留为别名。

## 1. 间距（4px 基准）

| 变量 | 值 | 用在哪里 |
|---|---|---|
| `--ds-space-1` | 4 | 图标和文字之间；标签和控件之间 |
| `--ds-space-2` | 8 | 同组控件之间；区块标题和内容之间 |
| `--ds-space-3` | 12 | 表单行之间；手机卡片内边距 |
| `--ds-space-4` | 16 | 电脑卡片内边距；卡片之间 |
| `--ds-space-5` | 24 | 大区块之间 |
| `--ds-space-6` | 32 | 页面左右留白（电脑） |

- 高度：顶栏 / 底栏 `--ds-bar-h` 48（手机 44）；控件 `--ds-control-h` 32；ⓘ 等小图标的点击区不小于 32。
- 列表行：上下内边距 6、左右 12–16。双语行的目标高度约 52px。
- 不要卡片套卡片：卡里的分组用一条分隔线，不再加边框和底色。
- 首屏指标：工作台在电脑 1280×800 下首行 y ≤ 300，一屏 ≥ 9 行；手机 390×844 一屏 ≥ 4 行。

## 2. 字号（5 级）、字重（3 档）、行高（3 档）

| 级别 | 变量 | 电脑 / 手机 | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|
| Title | `--ds-fs-title` | 20 / 18 | 600 | 1.25 | 页面标题（片名 + 集号） |
| Head | `--ds-fs-head` | 16 | 600 | 1.25 | 区块标题、卡片标题；**字幕中文行用 16/500** |
| Body | `--ds-fs-body` | 14 | 400（强调 600） | 1.45 | 正文、按钮、文件名 |
| Meta | `--ds-fs-meta` | 13 | 400（标签 500） | 1.4 | 说明、表单标签、时间码、原文行 |
| Micro | `--ds-fs-micro` | 12 | 500 | 1.25 | 只用于徽章和计数；**全站最小 12px** |

- 字重只用 400 / 500 / 600。数字要强调时用颜色或等宽字体，不用 700 / 800。
- 字色只分三级：`--ds-ink`（主）、`--ds-ink-2`（82%，标签和次要正文）、`--ds-ink-3`（62%，说明）。不再用 58% 的 faint 色写说明文字。
- 层级不能倒挂：标题必须比它下面的内容大一级，或者同号但更粗。工作台里字幕本身是主角，区块名降成 Meta 级的标签（`.ds-label`）。

## 3. 文案详略规则

1. 每个控件最多一行说明，≤ 20 个汉字，写「对用户的结果」，不写实现方式。
2. 技术名词（Script Info、带状搜索、libass、字段名）只出现在 ⓘ 里。ⓘ 的内容也只写一两句。
3. 同一件事只说一次：有图标就不再加提示句；有标题就不在副标题里重复标题。
4. 安心提示（「仅本机处理」）常驻，但放在 Meta 级。
5. 出错提示要写「发生了什么 + 怎么办」，并且常驻到用户关闭。
6. 不弹浏览器原生确认框：待复核只做页面内提示，不拦截预览和导出。
7. 用词统一：「原文名」「中文 + 原文名」「另附 SRT」「另附 HDR 版」「历史」。

## 4. 入口显眼度规则

| 等级 | 样式 | 适用 |
|---|---|---|
| 主操作 | 实心橙色，每屏最多 1 个 | 下一步、导出字幕 |
| 次操作 | 浅底加文字 | 字幕样式、显示全部 |
| 核心入口 | **图标加文字**（`.ds-entry`、托盘控件），所有页面固定位置 | 历史、隐私、反馈 |
| 纯图标 | 只用于大家都认识的动作（关闭、撤销、重做、播放、编辑），必须有中文 aria-label 和 title | — |
| ⓘ | 只放补充说明，点击区 ≥ 32 | — |

- 不显眼的功能不要做成大按钮（例如「手动匹配」改成文字按钮）。
- 已经下线的功能不留入口（「视频文件对比」已删）。
- 同一个入口在所有页面的位置和数量保持一致（「历史」在三幕都显示）。

## 5. 组件清单（ds.css）

`.ds-title` `.ds-head` `.ds-body` `.ds-meta` `.ds-label` `.ds-mono` `.ds-info` `.ds-select` `.ds-check` `.ds-segmented` `.ds-form`（96px 标签列加控件列，手机上变一列） `.ds-entry` `.align-choice` `.export-menu`

## 6. 深浅表面

- 浮层（导出菜单、下拉）一律用不透明的浅色面板（`data-surface="cream"`），在深色预览页里也一样，这样不会再出现深色字压在深色底上。

# v1.1 修订（2026-10-13）

## 2.1 竖向节奏（强制）
只允许以下四种块间距，任何组件不得自定 `gap-*/mt-*/py-*` 作为块间距：

| Token | 桌面 | 手机 | 用途 |
|---|---|---|---|
| `--ds-gap-item` | 8 | 8 | 标题 → 其内容；同一组内的行 |
| `--ds-gap-group` | 12 | 12 | 卡片内的分组；表单行；工作台卡片之间 |
| `--ds-gap-section` | 24 | 16 | 页面边缘 → 首张卡片；卡片/分区之间 |
| `--ds-pad-card` | 16 | 12 | **唯一**内边距：卡片、底板、停靠面板、弹窗、提示条（v1.2） |

- 导入页：左影片卡与右栏顶边对齐（`items-start`），两者内边距同为 `--ds-pad-card`。
- 原生类：`.ds-card`、`.ds-section`（标题+内容，间距 item）、`.ds-well`。
- 正文宽度：说明类页面（关于、反馈）统一 `max-w-3xl`，段落 `max-w-[68ch]`，避免短行与大面积留白。

## 6. 预览（第三幕）选项面板
### 6.1 停靠面板（唯一）
- 画幅、剧照、样式预设、字幕样式、导出：全部在**同一个右侧停靠面板**中打开，不再使用下拉菜单。
- 面板是文档流中的兄弟节点，**不是浮层**：桌面宽 360px，预览区相应缩小并保持比例，画面始终完整可见。
- 手机（<1024px）：面板变为画面下方的底部面板（最高 48%），画面在上方缩放后保持可见。
- 面板表面见 v1.2 §6.1（沿用原样式参数抽屉）。浮在内容上的菜单必须用实色；其他位置原有的毛玻璃（顶栏、播放条、提示条、遮罩）保持不变。
- 再次点击同一入口、点 ✕ 或按 Esc 关闭。选择即生效，面板保持打开以便对照。
### 6.2 浮层（其余位置）
- 仍为浮层的菜单（如字幕文件选择）：实色 `--v5-panel-raised`、1px 描边、两层阴影；左对齐触发按钮，靠右边缘时右对齐，始终在视口内。
### 6.3 关灯
- 关灯是画面级视图开关，放在播放条右侧、与「画幅辅助线」并列，不放在选项按钮行。
### 6.4 特殊行导航
- 类别标签带数量：歌词 / SDH / 长对话 / 标题告示；数量为 0 的类别不显示。
- 点击类别：选中并定位到第一处；旁边翻页器「‹ n / N ›」在该类内前后切换（循环）。
- 选中类别时时间轴显示该类刻度；每次跳转在落点短暂高亮（尊重 reduced-motion）。
- 首次进入预览显示一次简短提示，可关闭（localStorage `saiko_coach_special`）。

## 7. 文案规范
- 书面、专业、简洁；不用口语词（「片子」「即可」「一下」「你」「会帮你」）。
- 句式：说明类用陈述句，结尾不用感叹号；提示用「需先…」「将…」「可…」。
- 动词统一：添加（不用「拖入/加入」混用）、清除（本地数据）、删除（单条）、更换（候选/剧照）。
- 术语统一：主字幕 / 原文；标题告示（不再用「画面字」「画面文字」）；SDH（不再用「声音描述」）；长对话；本地（不用「本机」于新文案）。
- 数字与单位之间留空格（「30 天」「40 行」）；中英文之间留空格（「将 SDH、歌词…」）。
- 完整对照表见 `docs/copy-v1.1.md`。

## 待定问题
- 「样式参数」面板仍提供自由滑杆（整体缩放、字号、底部距离），与「有限固定预设、不做自由微调」的产品原则冲突。本版未删除，需 Derek 决定：保留 / 收进「高级」/ 改为档位。

# v1.2 修订（2026-10-13）

## 2.2 内边距：唯一 token
- `--ds-pad-card` 桌面 16 / 手机 12，四边一致；文字或控件到卡片内边的距离必须等于它（±1px）。
- 卡片、内嵌底板、选项卡片（智能/精校）、停靠面板的头部与内容、弹窗、历史面板头尾、导出面板各段、提示条都只用这个 token。列表行左右也用它，保证行文字与卡片标题左边缘对齐。
- 竖向只允许两种例外：头部/工具条的上下用 `--ds-gap-group`（12），列表行上下用 `--ds-gap-item`（8）。
- 卡片顶边 → 首个标题 = `--ds-pad-card` + 1px 描边（标题行高 1.25，没有额外 margin）。

## 2.3 圆角
- 保持现有圆角 token（sm 6 / md 8 / lg 12 / xl 20），不引入新的视觉风格。
- 只修正嵌套失衡：内层圆角不得大于外层。卡片（8px）里的底板从 12px 改为 6px；其余不变。
- 对齐原则：同一卡片内所有文字左边缘落在 `--ds-pad-card` 网格上；上下内边距相等。

## 6.1 补充：停靠面板表面
- 停靠面板沿用原「样式参数」抽屉的表面（`.theater-style-shell`：深绿 78% + blur 18px），Derek 认可这个观感；它停靠在画面旁边，不覆盖视频，所以可读性没有问题。
- 只有压在视频上的半透明下拉菜单是可读性问题，已经全部改为停靠面板，因此不再存在。
