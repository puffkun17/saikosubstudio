## 「样式」面板

1. **样式列表**：默认经典、libass 完整 ASS、深蓝描边（固定）；源文件内嵌样式（导入的 .ass 带样式时出现）；用户另存的配置；「从文件获取」的结果（ASS、截图）。点一项即选中，预览与导出同时生效。
2. **从文件获取**：结果直接加入列表并选中。
3. **显示亮度**：SDR / HDR 柔和 / 更暗 / 影院，单独一组。
4. **微调**：滑块、字体、颜色、输出规格、歌词，叠加在选中项之上。改动后，所选项显示「已微调」，标题栏出现「重置为『…』」。「另存微调」会把当前效果存成新的一项（基于固定预设时只存差值，保留预设的导出排版）。

辅助字幕策略不属于任何样式项：选样式、重置、另存都不会改它。
